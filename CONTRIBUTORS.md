## DeepSeek

DeepSeek assisted in designing, implementing, testing, and documenting this
plugin through DeepSeek Harness.

DeepSeek's GitHub presence is the [deepseek-ai](https://github.com/deepseek-ai)
organization. GitHub's contributor widgets and API count users whose email is
linked to a GitHub account. Organizations cannot be commit authors, and no
official DeepSeek user account is available for this attribution. The release
commit carries `Co-authored-by: DeepSeek <noreply@deepseek.com>` so the
contribution is visible in the commit metadata. If GitHub cannot map that
email to an account, the repository sidebar and contributor API may still show
only the maintainer. This file records the contribution without inventing or
misrepresenting an account.

DeepSeek 在 GitHub 上是 [deepseek-ai](https://github.com/deepseek-ai) 组织。GitHub 的贡献者展示和 API 统计绑定到 GitHub 账号的邮箱；组织不能作为提交作者，也没有可绑定的 DeepSeek 官方个人账号。发布提交带有 `Co-authored-by: DeepSeek <noreply@deepseek.com>`，共同作者信息会出现在提交元数据中；如果该邮箱无法映射到账号，仓库侧栏和 Contributors API 仍可能只显示维护者。这里记录 DeepSeek 的贡献，但不伪造或冒用账号。
