# Obsidian Skills for DSH

[中文](README.md) | [English](README.en.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | [Русский](README.ru.md)

Легкий плагин DeepSeek Harness для [официальных Agent Skills Obsidian](https://github.com/obsidianmd/obsidian-skills). На странице плагина можно проверить версию upstream и обновить навыки до выбранного Release.

## Зачем отдельная версия для DSH

Obsidian пока не предоставляет плагин для DeepSeek Harness. Этот репозиторий закрывает этот пробел: он использует официальные тексты навыков и добавляет манифест плагина DSH, проверку версии upstream и обновление всего дерева навыков.

## Особенности

- **Легкость**: регистрирует только семь навыков и не запускает внешние процессы.
- **Только навыки**: не включает CLI-утилиты Obsidian, Defuddle или Knap.
- **Чистота**: без MCP-сервера, фонового демона, телеметрии и учетных данных; GitHub используется только для проверки версии и обновления.
- **Прослеживаемость**: фиксирует версию upstream и соответствующий commit.
- **Обновляемость**: проверяет последний GitHub Release upstream и позволяет обновиться до него.

## Включенные навыки

| Навык | Назначение |
|---|---|
| `obsidian-markdown` | Obsidian Flavored Markdown: wikilinks, встраивание, callouts, properties |
| `obsidian-bases` | Представления, фильтры, формулы и сводки `.base` |
| `json-canvas` | Узлы, связи, группы и компоновка `.canvas` |
| `obsidian-cli` | Чтение и запись vault через Obsidian CLI; разработка плагинов и тем |
| `obsidian-headless` | Синхронизация и публикация vault через `ob` без настольного приложения |
| `defuddle` | Извлечение чистого Markdown из веб-страниц |
| `knap` | Рендеринг Markdown-шаблонов из данных JSON/CSV |

Навыки содержат только инструкции и не включают сами инструменты. `obsidian`, `ob`, `defuddle` и `knap` не входят в плагин и подчиняются разрешениям и подтверждениям текущей сессии DSH.

## Установка

В DSH откройте **Плагины**, выберите **Добавить плагин** и введите:

```text
https://github.com/WangJingJun-dev/obsidian-skills-for-dsh
```

После установки откройте новую сессию, чтобы загрузился каталог навыков. Если другой плагин регистрирует навык с тем же именем, DSH оставляет один согласно приоритету регистрации.

## Проверка версии upstream и обновление

Раздел **Версия навыков upstream** на странице плагина:

- показывает встроенную версию upstream, commit и время синхронизации;
- проверяет последний GitHub Release `obsidianmd/obsidian-skills` при открытии страницы;
- показывает **Обновить до vX** и ссылку на Release при наличии новой версии;
- кнопка **Проверить снова** обходит короткий кэш.

Обновление загружает тег выбранного Release, создает резервную копию и **полностью заменяет каталог `skills/`**. Поэтому добавленные, измененные и удаленные навыки точно соответствуют этому Release. При ошибке выполняется откат, частичное обновление не остается. На компьютере должен быть установлен `git`, а каталог плагина должен быть доступен для записи.

## Границы и разрешения

- Плагин не записывает данные в ваш Obsidian vault.
- Навыки, описывающие запись, используют реальные инструменты и подчиняются разрешениям DSH.
- MCP-сервер, фоновый демон, телеметрия и учетные данные не включены.
- Обновление изменяет каталог установленного плагина. При установке только для чтения возвращается ошибка без частичной записи.
